# zenn 執筆ガイド（STEP [2] 本文を書く前に読む）

## 読みやすさ

- **タイトル**: 具体的な成果物名（「〇〇で××を△△する」形式が強い）
- **冒頭 3行** で「何を作ったか・読者は何を得られるか」を言い切る
- **失敗談は宝物**: 成功手順だけより、試行錯誤の記録のほうが刺さる
- **再現手順** を最後に置く（コピペで動くコマンド）
- **小見出し頻繁** に切って、スキャンしやすく
- **絵文字は節アイコン程度** に留める（使いすぎると軽く見られる）

## 技術記事の構造テンプレ

```
## 何を作ったか（1枚絵＋3行）
## なぜ作ったか（動機・痛み）
## 結論（先に答え・ファイル構成）
## 最初の壁（上手くいかなかった方法）
## 正解アプローチ
## 実装のハイライト（コード）
## 全体の流れ（図）
## 再現手順
## 応用範囲
## 得られた学び
## まとめ
```

## frontmatter テンプレ

```yaml
---
title: "タイトル（60字以内目安）"
emoji: "🔧"            # 1文字の絵文字
type: "tech"           # tech or idea
topics: ["claudecode", "python"]   # 5個以内
published: false       # 初稿は必ず false
---
```

## トラブルシューティング

| 症状 | 原因 | 対処 |
|------|------|------|
| push したが Zenn に記事出ない | `published: false` のまま | true に変えて push |
| Zenn 側で記事が404 | slug にアンダースコア使用 | ハイフンに変更 |
| 画像が表示されない | ローカルパス指定 | `/images/<slug>/foo.png` で `images/` 配下に置く |
| プレビューでエラー | `zenn-cli` 未インストール | `npm install zenn-cli` |

## 初回セットアップ（リポジトリを作る時・作り直す時だけ使う）

```bash
cd "$ZENN_DIR"
git init
git remote add origin https://github.com/<YOUR_GITHUB>/zenn-content.git
git branch -M main
git push -u origin main
# Zenn dashboard で GitHub 連携設定
```

Zenn の dashboard で GitHub 連携（`<YOUR_GITHUB>/zenn-content`）を設定すれば、以後 push だけで記事追加・更新できる。
