# breadboard-diagram の知見（2026-10-06 時点・テーマ8/9 の図づくりで確かめた事実）

「確かめた」と「写真から読み取っただけ」を分けて書く。実物のブレッドボードで確認できたら、読み取りの行を直す。

## 1. T型基板（Raspberry Pi Breakout Board）のピン名と並び

出典: 作者の学生実験の補足資料 テーマ8 p.5・テーマ9 p.5 の写真（ブレッドボードの上に T型基板がある向き）。上から下の順。

| 行 | 左の列 | 右の列 |
| --- | --- | --- |
| 1〜4 | SDA, SCL, GCLK, GND | TXD, RXD, GND, IO18 |
| 5〜8 | IO17, IO27, IO22, MOSI | IO23, IO24, IO25, CE0 |
| 9〜12 | MISO, SCLK, IDSD, IO5 | CE1, IDSC, GND, IO12 |
| 13〜16 | IO6, IO13, IO19, IO26 | GND, IO16, IO20, IO21 |

- 行番号は図の中だけの数え方（SDA/TXD の行が1）。実物の印字の数字は T型基板の差す位置で変わる（補足資料の2枚の写真でも1行ずれていた）。
- 角の4ピン: 左上が「3V3」「GND」、右上が「5V」「GND」。左右のレールにつながる（補足資料 p.3）。
- IO の数字は GPIO（BCM）番号。`gpio -g` で指定する数字と同じ。ラズパイ 5 の `gpio readall` で、BCM 23・24・25 は wPi 4・5・6、SCLK・MOSI・MISO・CE0 は wPi 14・12・13・10 と確認した（2026-10-06）。

## 2. 穴の幾何（写真から読み取り・実物未確認）

- T型基板の足は、左の列が d 列、右の列が g 列に入る。基板の赤い部分が e・f 列と溝を覆うので、行 1〜16 で使える穴は、左が a・b・c、右が h・i・j（各ストリップに空き3つ）。
- 5穴が1ストリップ（同じ行の a〜e、f〜j）。ジャンパー線は、そのピンと同じ行の空いた穴に差す。
- 左のレール: 外側の列が 3.3 V、内側の列が GND。右のレール: 内側の列が 5 V、外側の列が GND。補足資料 p.3 の赤い印（レールの色の線）と角のピン名の位置から読み取った。
- レールは、上の4穴（赤丸）だけ使ってよい。その下はテープが貼ってあって使えない（補足資料 p.3「テープが貼ってある端子は使用しないこと」）。

## 3. 配線の本数の検算

器材表のジャンパー線の本数と、自分で数えた本数が一致した。数が合わなければ配線の考え方を疑う。

- テーマ8（LED3個）: 6本 = GPIO→LED が3、抵抗→GND が3。
- テーマ9（MCP3208）: 11本 = GND 3（AGND・DGND・可変抵抗器）＋ SPI 4（MOSI・MISO・SCLK・CE0）＋ CH0 1 ＋ 3.3 V 3（VDD・VREF・可変抵抗器）。

## 4. 部品の事実

- LED: 長い足がアノード（A、GPIO 側）、短い足・平らな側がカソード（K、抵抗経由で GND）。330 Ω は橙橙茶金。解説の例の色は GPIO23＝青、24＝緑、25＝赤（実験解説 p.13・p.15）。
- MCP3208: 1〜8 番が CH0〜CH7、9 DGND、10 CS/SHDN、11 DIN、12 DOUT、13 CLK、14 AGND、15 VREF、16 VDD（補足資料 テーマ9 p.5 の回路図）。資料の写真は T型基板が下なので、T型基板が上の図にするには180°回す。回すと左の列は上から 9→16 番、右の列は上から 8→1 番、切り欠きは下、1番ピンの印は右下になる。
- 可変抵抗器 10 kΩ: 3本足を縦に並んだ3行に差す。上の足 GND、中央の足 CH0、下の足 3.3 V（補足資料 p.5 の回路図の向き）。

## 5. 配線の描き方で効いたこと

- 配線が7本を超えると、列に沿った縦線が終点の穴の上を通って、どの穴に差すのか読めなくなる。始点から**左右へ → 縦へ → 終点の穴へ横から入る**直角配線にして、縦線を穴の列の外（左の余白）に出す。
- 通り道（レーン）の並びと始点の行は、全探索で決める（`optimize_wires`）。テーマ9は 6×6×6×6×6 通りを調べて、交差 8 か所が最小だった。最初に手で決めた並びは、別の配線の端の穴の上を通っていた。
- `dot_on_wire` は「他の配線の端の穴から 5.5 px 以内を線が通る」並びを捨てる。これを入れる前は、検査を通っても図の上で穴が読めない図ができた。
- 番号札は始点と終点の両方の近くに付ける。線の途中の1つだけだと、混んだ所で重なって読めない。
- 柱になる「ここは1か所だけ交差が残る」は無理に消さない。図は完全な平面でなくてよく、番号と配線表で読めれば足りる。

## 6. 紙面の作り方で効いたこと

- A4 縦・1枚に収める。あふれたら、右の列（図の横）に余白があるので、箱を移す。下段は左右2つの箱にして、片側に2つ積む。
- チップの文字（ピン名）に線や題字を重ねない。題字（MCP3208）はチップの下へ。
- PDF は Chrome ヘッドレス。入出力は絶対パス、`--no-sandbox` と毎回新しい `--user-data-dir`（前回のロックで固まる）。出力は `to_pdf` に任せる。
- 確認用の PNG は、ページ数が減った時に古いページが残らないよう、書く前に同じ名前の古い PNG を消す（`page_pngs`）。

## 7. この図の限界

- 配線は回路図と照合してあるが、**実物のブレッドボードに配線して動かしたわけではない**。LED と MCP3208 は未接続のまま作った。穴の幾何（§2）は写真からの読み取り。
