## 書き手の説明なしで意味が1通りに決まる文（2026-10-01・check_ai_likeness の AIK1〜AIK3）

元の資料は Kiminori Yokoi「AI臭い文章とは何なのか」（豊洲会 2026-09-28・https://speakerdeck.com/nasuvitz/ai-kusai-bunshou-toha-nanina-no-ka ）。
本人の指摘「今のスライド生成は結局何を言いたいのか伝わらない」を受けて、スライド・文章全般と同じ原理をレポートにも入れた。
言い回しの一部は nanaism/yomiyasu（MIT）の一覧を直して使った。

AI臭い文章は「日本語がおかしい文章の一種」で、読み手（採点する教授）に文脈の補完を求める。特徴は3つ。
1. **不要な対比・否定・留保から入り、主文を直接書かない**（「重要なのは、」「結論から言うと」「単なる〜ではない」）
2. **抽象語や比喩の動詞で、何をするのかが曖昧**（前提が崩れる・原因を潰す・地味に効く・深掘り）
3. **短文・対句・不自然な読点・名詞化で、内容以上に印象的に見せる**（「前提を、経路が…」の溜めの読点・語を入れ替えた反復・ダッシュ「—」で区切る）

（下の表は書き方の作例。実験の値ではない。数値は必ず実測の表から書き、作らない）

| ❌ 書かない | ✅ 書き方 |
|---|---|
| 重要なのは、抵抗の温度依存である。 | 抵抗値は温度とともに増加した（図3）。 |
| 誤差の原因を1つずつ潰した。 | 誤差の原因として接触抵抗と目盛りの読み取りを調べ、端子を締め直して接触抵抗を下げた。 |
| ここを読み違えると前提が崩れる。 | 式 (3) は測定器の入力インピーダンスを無限大とみなして導いたため、入力インピーダンスの低い測定器では成り立たない。 |
| 測定値を、表が代わりに示す。 | 測定値を表2に示す。 |
| オシロスコープ——これが今回の主役である。 | オシロスコープで出力波形を観測した。 |

- **レポートで正当な物**（拾わない）：前者・後者、「スイッチを閉じた瞬間」、「トグルスイッチを ON 側に倒す」、真理値表・結晶・凝縮・装置・熱量、受け身、「コンデンサは直流を通さない。交流は通す。」のような性質の対比、表紙の副題の「—」、コードの行。
- 判定の問い：**この文だけで、誰が（何が）・何を・どうした（どうなった）が1通りに決まるか**。決まらない語には「これってどういう意味？」と聞き、答えの文をそのまま本文にする。
- 機械：`check_ai_likeness.py` の AIK1〜AIK3（NG）と参考層。規則の一覧と外す物は同ファイルの AI_PATTERNS のコメント。回帰の試験は `tests/test_check_ai_likeness_yokoi.py`（作者の環境では別スキルの試験集 `humanize/scripts/tests/ai_smell_cases.json` も読む。このリポジトリには含まれず、無ければその試験は skip になる）。

## 変数記号の選び方

レポート本文・式・表ヘッダで使う変数記号は、**プログラミング由来の略語ではなく数学慣習の1文字記号**を選ぶ。

| 用途 | 推奨 | 避ける |
|---|---|---|
| ループ回数・整数パラメータ | `n` `k` `m` | `arg` `count` |
| 関数の引数を一般的に指す | 日本語「引数」 | `arg` `param` |
| 配列・離散インデックス | `i` `j` `k` | `idx` `index` |
| 一時量・中間変数 | `x` `y` `s` | `tmp` `buf` |
| 関数の戻り値 | その物理量の記号（`V` `I`） | `ret` `result` |

C コードのリスト中の仮引数名はそのままでよい（`wait_count` 等）が、**本文や数式で参照する**ときは数学記号に置き換える。初出時に必ず定義：「wait 関数の引数（ループ回数）を n と表す」。

## 理系実験レポートのグラフルール（必須・印刷白黒前提）

**matplotlib 自作グラフは `scripts/graph_lib.py` を必ず使う**（以下のルールが自動適用される。手書き再実装しない）:

- タイトルなし（キャプションは本文）
- 軸ラベル = `物理量 [単位]`（例: `電圧 [V]`）→ `style_axes(ax, xlabel, ylabel)`
- マーカー: サイズ10、系列順に ●黒丸塗り→△白抜き三角→■塗り四角→◇白抜き菱形 → `plot_series(ax, x, y, series=N)`。理論曲線は `plot_theory`
- **点を線で結ぶかどうか（P-060）**: 近似直線か理論曲線を同じ系列に重ねる時だけ `line=False`（点だけ）。曲がる系列・近似しない系列は `line=True`（既定）で点どうしを結ぶ。条件の違う点は別の記号にして結ばない（テーマ5 図6 で本人「点を結ぶ線がない」）
- 線色・マーカー色: 全て黒(#000000)。カラー禁止
- 目盛り: 内向き・上下左右の枠に付く、目盛り数値は軸外側
- Y軸グリッドライン: 薄灰色細線 / X軸: なし
- フォント: Century + MSゴシック、11pt以上
- 対数軸: 指数表記(10³)でなく普通の数字(1000)表記（自動）
- 凡例: 枠なし（`add_legend`）。1系列なら凡例なし
- 記入用の空グラフ枠（プレレポート）: `blank_frame(xlabel, ylabel, xlim, ylim, xscale='log')`
- **⚠️ 日本語と数式記号($…$)を同じラベル文字列に混ぜない**。混ぜると日本語が全部豆腐□になる（2026-07-03 実測）。`ml('V_{out} [V]')` は可、`ml('出力電圧 V_{out} [V]')` は不可（ValueError で停止）→「出力電圧 [V]」と日本語だけにするか記号だけにする
