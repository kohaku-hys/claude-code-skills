## 暗号化（パスワード保護）PDFの扱い（STEP 0d・テーマ9で確立）

教科書・要領・表紙PDFが暗号化されていると **Read ツールは直接開けない**（"PDF is password-protected"）。多くは**所有者PWのみで、ユーザPWは空**なので空文字で開ける：

```python
import fitz
doc = fitz.open(path)
if doc.is_encrypted: doc.authenticate("")   # 空PWで開く
for i in range(doc.page_count):
    doc[i].get_pixmap(dpi=160).save(f"src_pages/page{i+1}.png")  # PNG化して Read で読む
```

`pikepdf.open(path, password="")` でも可。空PWで開けない場合のみユーザーにPWを聞く。

```python
import sys, os; sys.path.insert(0, os.path.expanduser(r'~/.claude/skills/report/scripts'))
```

```python
draw_resistor(ax, 1, 4, 'right', 'R = 1 kΩ', label_side='top')          # 上辺
draw_inductor(ax, 4, 4, 'right', 'L = 10 mH', label_side='top', label_offset=0.55)
draw_dot(ax, 8, 4)                                                       # 接続点
draw_capacitor(ax, 8, 4, 'down', 'C = 0.01 μF', label_side='left', length=1.5)
draw_terminal(ax, 9.5, 4)                                                # 測定端子
draw_gnd(ax, 4, 0)
save_circuit(fig, 'fig1_circuit.png')   # ★保存の前に文字かぶりを自動で機械検査（1件でもあれば停止）→ その上で Read で目視確認
```

**文字かぶり検出（`assert_no_overlaps` / `find_overlaps`）**: 描画済み図の各ラベルの表示bboxを取り、(1)ラベル同士の重なり (2)ラベル文字を配線・素子線が横切る、を検出する。`assert_no_overlaps(fig, ax)` は1件でもあれば `AssertionError` で停止。**2026-09-28 から `save_circuit` が保存の前に図の全ての軸へ自動で呼ぶ**（呼び忘れで重なった図が出ない。自分で先に呼んでいても二重になるだけで害はない）。件数だけ見たいときは `find_overlaps(fig, ax)` がリストを返す。重なりが出たら `label_side`（top/bottom/left/right）や `label_offset` を変える、縦素子はラベルを枝の外側へ、素子間隔を広げる。shrink=0.20（既定）でリード線がbboxの端をかすめる正常配置は誤検出しない。**負の対照で妥当性確認済み**（わざと重ねた2ラベル・線上ラベルは検出、離した配置は0件）。

- 新部品: `draw_inductor`（コイル）/`draw_zener`（ツェナー・三角の頂点=カソードが direction 側）/`draw_switch`/`draw_battery`（direction 側が+極）/`draw_variable_resistor`/`draw_terminal`/`draw_current_arrow`（素子に重ねない）
- 縦素子のラベルは `label_side='left'`（コイルのこぶ・電圧計の枝と反対側）にすると重ならない

## DOCX→PDF（全ページ目視検証用・Word COM）

**ハングの正体はゾンビ WINWORD.EXE**（2026-07-03 実証: 残骸プロセスをkillしたら即成功）。手順:

```bash
taskkill //F //IM WINWORD.EXE   # 先にゾンビ掃除（居なければエラーでOK）
timeout 100 py export_pdf.py    # timeout保険つきで実行
```

```python
import win32com.client
word = win32com.client.DispatchEx("Word.Application")
word.Visible = False; word.DisplayAlerts = 0
try:
    doc = word.Documents.Open(SRC, ReadOnly=True)
    try: doc.ExportAsFixedFormat(DST, 17)   # 17 = wdExportFormatPDF
    finally: doc.Close(False)

    word.Quit()

```

## Excelグラフの画像エクスポート（STEP 2b・add-in作成済みの場合）

Excel add-in 側で作成済みのグラフを `win32com` でエクスポートする：

```python
import win32com.client
def export_charts_from_excel(xlsx_path, output_dir):
    excel = win32com.client.Dispatch("Excel.Application")
    excel.Visible = False
    wb = excel.Workbooks.Open(xlsx_path)
    for ws in wb.Worksheets:
        for i, chart in enumerate(ws.ChartObjects()):
            chart.Chart.Export(f"{output_dir}/{ws.Name}_chart{i+1}.png", "PNG")
    wb.Close(False); excel.Quit()
```

## add_para / add_equation ヘルパ（必須・rich-text経由）

`scripts/rich_text.py` の `add_rich` / `set_jp_font` を import して使う：

```python
import sys, os; sys.path.insert(0, os.path.expanduser(r'~/.claude/skills/report/scripts'))
from rich_text import add_rich, set_jp_font

def add_para(text, indent_first=True):
    p = doc.add_paragraph()
    if indent_first:
        p.paragraph_format.first_line_indent = Pt(10.5)
    add_rich(p, text, font_size=10.5, font_jp='ＭＳ 明朝')  # ← 必ず rich 版。font_jp は Normal スタイルに合わせ明示（rich_text の既定は游明朝）
    p.paragraph_format.line_spacing = 1.4
    return p

def add_equation(text, num=None):
    p = doc.add_paragraph()
    p.alignment = WD_ALIGN_PARAGRAPH.CENTER
    add_rich(p, text, font_size=10.5, font_jp='ＭＳ 明朝')
    if num is not None:
        run = p.add_run(f'    （式{num}）')
        run.font.size = Pt(10.5); set_jp_font(run)
    return p
```
