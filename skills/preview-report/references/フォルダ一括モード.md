# preview-report フォルダ一括モード詳細（共有フォルダURL → 全動画列挙 → 回ごとに予習）

## いつ使うか

個別の動画URL（`stream.aspx` 単体）ではなく、**SharePoint/OneDrive の共有フォルダURL**（`AllItems.aspx` や `?id=` を含むリンク。1フォルダに複数回分の動画）を渡されたとき。

判定の目安：
- URLに `stream.aspx` → 単体動画。Quick / CDP モードへ。
- URLに `sharepoint.com` ＋ `AllItems.aspx` / `Forms` / `?id=` → フォルダ。**このモードへ。**

## エンドツーエンドの流れ

1. **smoke_test を実行**: `python ~/.claude/skills/preview-report/scripts/smoke_test.py`（数秒）。FAIL が出たらそのモジュールを直してから進む。

2. **フォルダを列挙**（正典コマンドは `sharepoint_folder.py list-folder`）
   ```bash
   python ~/.claude/skills/preview-report/scripts/sharepoint_folder.py list-folder "<共有フォルダURL>"
   # 別科目で名前パターンが違うとき:
   python ~/.claude/skills/preview-report/scripts/sharepoint_folder.py list-folder "<URL>" --rule generic --use-fallback
   ```
   内部で Chrome を起動（または再利用）し、Page.navigate → ロード待ち → **単一の Runtime.evaluate で全件列挙** → グルーピングして UTF-8 JSON（既定 `preview_capture/folder_manifest.json`）へ書き出す。stdout には `STATUS=... count=... json=<絶対パス>` だけが ASCII で出る。`preview.py list-folder` も同じ `STATUS=` 契約だが、一括モードの判定は `sharepoint_folder.py` 直接実行が基本。

3. **STATUS で必ず分岐する**（stdout の `STATUS=` 文字列が第一の判定材料。Read 不要・ASCII 安全）
   - `OK` → 手順4へ。
   - `OK_TRUNCATED` → 仮想化リスト末尾未到達で打ち切り（取りこぼしの恐れ）。`--timeout` を伸ばして再実行するか `log.truncated` を確認し、件数を鵜呑みにしない。
   - `AUTH_REQUIRED` → **開いた Chrome で MS アカウントにサインインしてから同じ list-folder を再実行**。件数やファイル名を勝手に埋めない。`log.auth_recovered_but_reexpired=true` なら Cookie 未保存（App-Bound 暗号化で復号失敗の可能性）→ プロファイル確認。
   - `EMPTY` → 0件成功。フォルダが空か UI 変更でセレクタ不発。JSON の `log.selector_hit` と `final_url` を確認。ファイル名を推測で作らない。
   - `CDP_DOWN` / `TIMEOUT` → 障害として扱いトラブルシュート。捏造での穴埋めはしない。

4. **manifest を Read ツールで読む**（stdout の JSON 絶対パス）。**コンソールに日本語を print すると文字化けする**ので、ファイル名は必ず JSON 経由で読む。キー：
   - `files` … DOM 実在名のみ（推測ゼロ）
   - `groups.lectures` … 回ごとの整形済みビュー（`videos[].id / filename / topic`）。**1回 = 1 Word の単位。**
   - `groups.matched` … 回キー（`"5"` 等）基準のマッチ一覧
   - `groups.by_kai_sorted` … 存在する回の昇順リスト
   - `groups.unmatched` … パターン外（他科目・サムネ・サブフォルダ等）を捨てずに可視化

5. **欠番・unmatched をそのまま受け入れる**: `by_kai_sorted` に無い回は欠番。**連番補完・ダミー生成は一切しない**（捏造禁止）。`unmatched` はユーザー文脈で含否を判断。

6. **対象回を選ぶ**: 指定回の `groups.lectures` エントリの動画群をサブ番号 `NN_1, NN_2, …` 順で取り出す。指定が無ければ `by_kai_sorted` と各回の `topics` を提示して確認。

7. **回ごとに Quick / CDP 判定へ合流**: `05_1_...` のように読める名前なら Quick。opaque なら stream.aspx を開いて CDP（`preview.py capture` または `capture-tabs`）。**`capture-tabs` の前提**: フォルダ表示タブは閉じ、対象回の `stream.aspx` タブだけを開いた状態で実行（`--splits` 既定 10）。

8. **回ごとに並列 Agent でレポート生成（1授業 = 1 Word）**: 複数回頼まれたら回ごとに 1 message で Agent を並列発行。1回分の N 本は 1 つの `.docx` に `§1, §2, …`。ファイル名は回数のみ（サブ番号なし）。

9. **フォルダを開いて Chrome を終了**。

10. **skill-memory に追記**: 効いたセレクタ（`log.selector_hit`）・スクロール回数・件数・認証復帰の有無。

## list-folder のオプション

| オプション | 既定 | 意味 |
|------|------|------|
| `--out` | `preview_capture/folder_manifest.json` | 出力マニフェスト JSON の絶対パス |
| `--exts` | `mp4,mov,wmv,avi,mkv,m4v` | 拡張子フィルタ（カンマ区切り・大小無視・末尾アンカー） |
| `--rule` | `default_hanten` | グルーピング規則。`generic` は科目非依存の緩い既定 |
| `--use-fallback` | OFF | primary が外れた名前を緩い fallback で救済（`via='fallback'`） |
| `--recursive` | OFF | 既定は表示中フォルダ直下のみ。サブフォルダ混在は `unmatched` で可視化 |
| `--auth-wait` | 120 | 認証復帰ポーリングの上限秒。超過で `TIMEOUT` |
| `--timeout` | 90 | ナビゲート/列挙の上限秒 |

STATUS と終了コード（`sharepoint_folder.py` 直接実行時）：`OK`/`OK_TRUNCATED`=0 / `AUTH_REQUIRED`=2 / `CDP_DOWN`=3 / `TIMEOUT`=4 / `EMPTY`=5。
※ `preview.py list-folder` 経由では exit code が立たないため stdout の `STATUS=` で判定。
