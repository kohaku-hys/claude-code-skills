# アジェンダ生成スキル

> **▶ 実行開始時の共通3点セット**（詳細 → `~/.claude/skills/shared-doc-rules/SKILL.md` §8〜§10）
> 1. 📢 **公言**：応答冒頭で「agenda スキルを使っています」と必ず出力する（§10）
> 2. 🎯 **イシューからはじめよ**：手を動かす前に「このアウトプットで答えるべき問い」を1文で立て、合意してから進む（§8）
> 3. 🚫 **AIっぽさ撲滅**：生成文に量産コピー・定型句を使わない。仕上げに §9 の観点で見直す（§9）
> 4. `~/.claude/skill-memory/agenda.md` を読み込み、過去の改善を反映する

会議・授業・イベントのアジェンダを構造化して生成する。

実行開始前に:
1. `~/.claude/skills/shared-doc-rules/SKILL.md` を読み込む
2. `~/.claude/skill-memory/agenda.md` が存在すれば読み込む

---

## STEP 1: 情報収集

引数 `$ARGUMENTS` を確認し、不足情報をユーザーに確認する:

- **会議/イベント名**: 必須
- **日時**: 必須（開始時刻・終了時刻）
- **参加者**: 任意（役割・担当も含む）
- **議題リスト**: 必須（箇条書きでもOK）
- **目的/ゴール**: 推奨（会議で決めるべきこと）
- **場所/URL**: 任意
- **出力形式**: Markdown（デフォルト）/ Word / テキスト

---

## STEP 2: アジェンダ構造化

### テンプレート

```markdown
# {会議/イベント名} アジェンダ

- **日時:** {YYYY年MM月DD日 HH:MM〜HH:MM}
- **場所:** {場所 or URL}
- **参加者:** {名前（役割）}
- **目的:** {この会議のゴール — 1文で}

---

## タイムテーブル

| 時間 | 議題 | 担当 | 目的 | 備考 |
|------|------|------|------|------|
| HH:MM-HH:MM (Xmin) | {議題1} | {担当者} | {情報共有/議論/決定} | |
| HH:MM-HH:MM (Xmin) | {議題2} | {担当者} | {情報共有/議論/決定} | |
| ... | ... | ... | ... | |
| HH:MM-HH:MM (5min) | まとめ・次回アクション | 全員 | 決定 | |

---

## 事前準備

- [ ] {準備事項1}
- [ ] {準備事項2}

## 決定事項（会議後に記入）

-

## 次回アクション（会議後に記入）

| アクション | 担当 | 期限 |
|-----------|------|------|
| | | |
```

### 時間配分のルール
- 各議題に明示的な時間（分）を割り当てる
- 議論が必要な議題 > 情報共有の議題に時間を配分
- 最後に5〜10分の「まとめ・次回アクション」を必ず入れる
- バッファとして全体の10%を確保する

---

## STEP 3: 保存

1. `shared-doc-rules` の命名規則に従ってファイル名を決定
   - 例: `アジェンダ_サークル定例_20260417_v1.md`
2. ユーザー指定の形式（Markdown/Word/テキスト）で出力
3. `~/.claude/skill-memory/agenda.md` を更新
