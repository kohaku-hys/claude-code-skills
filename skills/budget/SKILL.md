## STEP 1: 情報収集

引数 `$ARGUMENTS` を確認し、不足情報をユーザーに確認する:

- **プロジェクト/イベント名**: 必須
- **総予算**: 推奨（上限がある場合）
- **期間**: 任意（単発 or 月次 or 年次）
- **費目リスト**: 必須（大まかでもOK — 細分化はこちらで行う）
- **通貨**: JPY（デフォルト）/ USD / THB 等
- **備考**: 助成金・スポンサー・自己負担の内訳があれば

## STEP 2: 予算表の構造

### シート構成

**Sheet1: 予算概要**
```
| 費目大分類 | 費目小分類 | 単価 | 数量 | 小計 | 備考 |
|-----------|-----------|------|------|------|------|
| 交通費    | 航空券     | ¥80,000 | 1 | =C2*D2 | 成田→バンコク |
| 交通費    | 現地交通   | ¥500   | 20 | =C3*D3 | BTS/MRT |
| 宿泊費    | ホテル     | ¥5,000 | 14 | =C4*D4 | |
| ...       | ...       | ...   | ... | ...   | |
| **合計**  |           |       |     | =SUM(E:E) | |
```

**Sheet2: 収支サマリー（予算規模が大きい場合）**
```
| 項目 | 金額 |
|------|------|
| 総予算 | ¥XXX |
| 支出合計 | =Sheet1!合計 |
| 残額 | =総予算-支出合計 |
```

### スタイルガイド
- ヘッダー: 青背景 + 白文字 + 太字
- 金額列: 右寄せ、通貨フォーマット、3桁カンマ区切り
- 合計行: 太字 + 上罫線（二重線）
- 列幅: 自動調整（日本語テキストの幅を考慮）
- フリーズペイン: ヘッダー行を固定
