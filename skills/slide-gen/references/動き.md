# 動きを付ける（motion.py・illust.py）— slide-gen から参照される実体

> 2026-10-13 新設。本人「手が動くスライドを作れるようになりたい」→ 選択式の回答「自分の pptx に動きを付ける／/slide-gen に足す／絵は Claude がフリー素材を探す／毎回、作り方の手順も付ける」。
> 練習場とお手本（作者の環境専用・このリポジトリには含まれない）：作業フォルダの `動くスライド\`（README.md・お手本_v4.pptx・編集画面の見方.png）。自分で作る時の目安にする。

## 何ができるか（ppt-master との分担）

| やりたいこと | 道具 |
|---|---|
| 出てくる効果だけ（フェード・ワイプ等）を全部の要素に | ppt-master の `svg_to_pptx.py -a auto` / `animations.json`（既存） |
| **軌跡で動かす・拡大/収縮・回転・消える・自動で戻す・繰り返し・変形・クリックの組み立て** | **`$T/motion.py`**（ppt-master の pptx_animations に無い物） |
| 本人が手で作った pptx に動きを足す | `$T/motion.py`（ppt-master を通さない） |
| 動かす絵（イラスト）を探す | `$T/illust.py`（いらすとや）。写真は `$SK/image_search.py` |

動きを付けるデッキは、svg_to_pptx を `-a none` で書き出し、動きは motion.py にまとめる（両方で付けると順番が読みにくい）。

## 手順

1. **何をどう動かすかを決める**：動きは「説明に要る所だけ」。動かす理由が言えない動き（飾りの回転・全部の要素のフェード）は付けない。本人に「どの枚の何を、どう動かすか」を選択式で聞く（例：①押す・戻る ②順番に出す ③変形で配置を変える）。
   - **動きの予算（2026-10-15 本人「動きができすぎてる」で、3クリックまでから下げた）**：1枚のクリックは2回まで・1回のクリックで動く物は2つまで・自動で繰り返す動きは1枚1つまで・強調と軌跡は1枚1〜2つ。motion.py はクリック4回以上／1クリック4つ以上／繰り返し2つ以上で止まる（3回・3つ・繰り返し1つは注意）。数字は `pptx_check.py` の `BUDGET` が正本。
   - 動きは「その枚の1つの伝えたいこと」を見せるために使う。スロットのレバー・リール3本・スマホ・景品を同じクリックで全部動かす、のような「全部が動く」場面は、見せたい1つ（例：リールが止まって当たる）だけ残す。
   - どうしても要る枚（くじの数字が回る、など体験そのものが動き）だけ、spec のその枚に `"busy": "理由"` を書く。理由はノートと `_動きの作り方.md` に残り、pptx_check もその枚は注意に下げる。
2. **絵を用意する**（要る時だけ）：`py -3 "$T/illust.py" "ばね" -o <proj>/images` → `_候補.png` を Read して選ぶ → 使わない候補は消す（image_sources.json の行も）。背景が透明な PNG を選ぶ（jpg は白い四角が出る）。検索で出ない時は言い方を変える（ばね→スプリング、手→指差し）。
3. **動かす物に名前を付ける**：
   - ppt-master のデッキ：SVG の動かす物に `id` を付ける（`<image id="hand" …>`・`<g id="force">`）。この id が PowerPoint の図形の名前になるのは、作者の改造版の ppt-master（svg_to_pptx に手を入れた版）だけ。上流の ppt-master では Group 12 のような作るたびに変わる名前になるので、書き出した後に `motion.py list` で名前を見て `#ID` か `text:文字` で指すか、PowerPoint の［ホーム］→［選択］→［オブジェクトの選択と表示］で手で名前を付ける。id は英数字の短い名前にする。
   - 本人の pptx：`py -3 "$T/motion.py" list <deck.pptx>` で名前を見る。「図 3」のような名前でも、#ID か `text:文字` で指せる。
4. **spec.json を書く**（形は motion.py の docstring）→ `py -3 "$T/motion.py" apply <deck.pptx> spec.json -o <deck>_v2.pptx`。元のファイルは上書きしない（版の数字を上げる）。
5. **確かめる**：`py -3 "$T/motion.py" verify <deck>_v2.pptx` → `_確認\_コマ送り.png` を Read。動く物が動いたか・止まるべき端が止まっているか・変形が滑っているかを見る（PowerPoint を本人が開いていても閉じない）。続けて `py -3 "$T/pptx_check.py" <deck>_v2.pptx` で ERROR 0（動きの予算と情報量）。
6. **本人に渡す**：pptx と一緒に **`<deck>_v2_動きの作り方.md`**（PowerPoint で同じ動きを自分で付ける番号付きの手順。同じ文がノート欄の【動きの作り方】にも入る）を必ず渡す。初めての動きなら、練習場の `編集画面の見方.png` のような画面の見方の図があれば、それと対応させて説明する。

## 動きの型（spec の書き方）

- **押して戻る**（手・ピストン）：`move`＋`back: true`＋`repeat: 3`。一緒に動く物は同じ `sec`・`back`・`repeat` にそろえる（そろえないと途中でずれる）。
- **ばねが縮む**：`scale` の x だけ（例 74%）＋**押した距離の半分の `move`**。拡大/収縮は絵の真ん中を基準に縮むので、半分ずらさないと壁側の端が浮く（2026-10-13 お手本で実証）。
- **順番に出す**：1クリック＝1つの [ ]。同じクリックで出す物は同じ [ ] に入れる（先頭がクリック時、残りは直前の動作と同時）。
- **流れ続ける背景**（潜水艦が進んで見える）：最初の [ ] に `{"auto": true}`、背景を `move` で左へ `repeat: "loop"`。主役は動かさない。
- **配置を変える**：次の枚に同じ名前の物を置き、`"transition": "morph"`。motion.py が前後の同じ名前に `!!` を付ける（Group 12・TextBox 5 のような決まりの名前には付けない）。

## 落とし穴

- **1つの物に2つ目の動きを付ける時は、必ず［アニメーションの追加］から**。上の効果の一覧から選ぶと、1つ目の動きと入れ替わる（2026-10-13 本人「ばねだと2つ動かせない 縮めるしかできない」）。motion.py は2つ目の動きの手順に、この注意を自動で書く。
- **同じ図形に軌跡を2つ続けて付ける時は、2つ目に `from_cm`（1つ目の終点＝元の位置からのずれ）を書く**。PowerPoint は軌跡を図形の元の位置から始めるので、書かないと2つ目の始めに図形が元の位置へ跳んで戻る（2026-10-15 本人「4枚目の動き座標がおかしい」。以前のデッキで、汚い水滴が地下へ下りた後に穴の中へ戻ってから横へ動いていた）。PowerPoint で手で付ける時は、2つ目の軌跡の始点（緑の三角）を1つ目の終点（赤の三角）に重ねる（motion.py が手順書に自動で書く）。
- グループの中の図形は単独で動かせない（PowerPoint と同じ）。動かしたい物はグループの外に出すか、グループごと動かす。
- 拡大/収縮は「縦横同じ %」か「片方 100」だけ。PowerPoint の画面で同じ設定を作れない値は motion.py が止める（本人が真似できなくなるため）。
- 「直前の動作の後」は使わず `delay` で代える（アニメーション ウィンドウでは「直前の動作と同時＋遅延」と表示される）。
- 自動で始まる組（auto）は最初の [ ] だけ。既に動きがある枚の後ろには足せない（`--replace` で作り直す）。
- 動画（video）が入った枚は別の動きの仕組みを持つので、motion.py は止まる。手で足すか `--replace`（動画の再生設定が消える）。
- 本人が手で付けた動きの後ろに足す時は `--replace` を付けない。付けると本人の動きが消える。
