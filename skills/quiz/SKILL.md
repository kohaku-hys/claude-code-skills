# テスト問題生成スキル

> **▶ 実行開始時の共通3点セット**（詳細 → `~/.claude/skills/shared-doc-rules/SKILL.md` §8〜§10）
> 1. 📢 **公言**：応答冒頭で「quiz スキルを使っています」と必ず出力する（§10）
> 2. 🎯 **イシューからはじめよ**：手を動かす前に「このアウトプットで答えるべき問い」を1文で立て、合意してから進む（§8）
> 3. 🚫 **AIっぽさ撲滅**：生成文に量産コピー・定型句を使わない。仕上げに §9 の観点で見直す（§9）
> 4. `~/.claude/skill-memory/quiz.md` を読み込み、過去の改善を反映する

授業内容・教科書・ノートから試験対策用の問題を自動生成する。

実行開始前に:
1. `~/.claude/skills/shared-doc-rules/SKILL.md` を読み込む
2. `~/.claude/skill-memory/quiz.md` が存在すれば読み込む

## STEP 1: 情報収集

引数 `$ARGUMENTS` を確認し、不足情報を確認する:

- **科目名/テーマ**: 必須
- **範囲**: 必須（章、トピック、授業回数など）
- **素材**: 推奨（教科書PDF、講義ノート、スライド等のファイルパス）
- **問題形式**: 以下から選択（複数可、デフォルト: 混合）
  - 選択式（4択）
  - 正誤判定（○×）
  - 穴埋め
  - 記述式（短答）
  - 計算問題
  - 論述式
- **問題数**: デフォルト20問
- **難易度**: 基礎(60%) / 標準(30%) / 応用(10%)（デフォルト比率）
- **出力形式**: Markdown（デフォルト）/ Word / PDF

## STEP 2: 問題生成

### 生成フロー

```
素材を分析
    ↓
重要概念・キーワードを抽出
    ↓
ブルームのタキソノミーに基づき問題を分類:
  - 知識（記憶）: 用語・定義の確認 → 選択式/穴埋め
  - 理解: 概念の説明 → 正誤/記述式
  - 応用: 計算・手順の適用 → 計算問題
  - 分析: 比較・原因究明 → 論述式
    ↓
難易度バランスを調整
    ↓
解答・解説を生成
```

### 問題テンプレート

#### 選択式
```markdown
**問{N}.** {問題文}

(a) {選択肢A}
(b) {選択肢B}
(c) {選択肢C}
(d) {選択肢D}
```

#### 計算問題（理工系）
```markdown
**問{N}.** {問題文}

条件: {回路パラメータ、初期条件など}

(1) {小問1}
(2) {小問2}
```

### 問題品質のルール
- **誤答選択肢はもっともらしく**: 典型的な誤解・計算ミスから導かれる値を使う
- **問題文は明確に**: 曖昧さを排除、必要な条件をすべて記載
- **計算問題は現実的な数値**: きれいな数値になるよう逆算して条件を設定
- **素材にない内容は出題しない**: 推測・一般知識での出題は禁止
- **解説は学習効果を意識**: なぜその答えになるか、どこを間違えやすいかを記載
- **計算問題の解答は独立検算（必須）**: 出力前に **subagent_type=math-checker** へ問題文・模範解答・誤答選択肢の導出値を渡して検算させる（間違った模範解答で勉強する事故の防止。subagent上限中は自分で py により全問再計算）

## STEP 3: 出力構成

### 問題編
```markdown
# {科目名} テスト問題集
**範囲:** {範囲}
**問題数:** {N}問
**制限時間目安:** {X}分

---

## 第1部: 基礎問題（{N}問）
...

## 第2部: 標準問題（{N}問）
...

## 第3部: 応用問題（{N}問）
...
```

### 解答・解説編（別セクション or 別ファイル）
```markdown
# 解答・解説

## 問1
**正解:** (c)
**解説:** {なぜこの答えになるか}
**関連ポイント:** {覚えるべき概念}
**よくある間違い:** {典型的な誤答とその原因}
```

## 注意事項

- **数式・計算問題は Unicode・プレーンテキストで書く**（LaTeX `$$` は環境で描画されない。例:「Vout = -Rf/Rin × Vin」「I = V / R」のように記述）。
- 解説・誤答原因などの散文は AIくささを避ける（定型的な締め・過剰ヘッジを排除。shared-doc-rules §9）。
- **捏造禁止**: 素材（授業ノート・教科書）に無い内容を出題しない。
